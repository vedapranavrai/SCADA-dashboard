A real-time industrial monitoring dashboard built with Python, InfluxDB, and Grafana.



\## What it does

\- Simulates factory sensors (temperature, pressure, flow rate)

\- Streams live data every second into InfluxDB time-series database

\- Visualizes data on a Grafana dashboard with alarm thresholds

\- Triggers red/yellow alarms when values exceed safe operating limits



\## Tech Stack

\- \*\*Python\*\* — sensor data simulator

\- \*\*InfluxDB 2.9\*\* — time-series database

\- \*\*Grafana\*\* — real-time dashboard and alerting
